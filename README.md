# 1PPS-Amplifier-PCB
1PPS signal buffer/inverter PCB for u-blox M8N GPS with 50 Ohm output
# Плата підсилення сигналу 1PPS

Плата призначена для буферизації та інвертування сигналу **1PPS від GPS-приймача u-blox M8N**.

Плата приймає логічний сигнал 1PPS від GPS-модуля, буферизує та інвертує його за допомогою логічного інвертора **74LVC1G04**, після чого передає сигнал на вихід через **BNC-роз’єм з узгодженням під 50 Ом**.

## Основні можливості

- вхід сигналу 1PPS від GPS-приймача;
- живлення 3.3 В;
- швидкодіючий логічний інвертор 74LVC1G04;
- інвертований вихід 1PPS;
- послідовне узгодження виходу для роботи з 50-омною лінією;
- вихід через BNC female PCB;
- вхід через Dupont 2.54 мм;
- роз’єм живлення Dupont 2.54 мм;
- розв’язувальний конденсатор 100 нФ;
- одностороння розводка плати;
- полігон GND;
- монтажні отвори під гвинти M2;
- підписи роз’ємів і контактів на шовкографії плати.

## Сигнальний тракт

```text
GPS 1PPS
   |
   v
J1 - 1PPS IN
   |
R1 - 100 Ом
   |
U1 - 74LVC1G04
   |
R2 - 33 Ом
   |
J4 - BNC 1PPS OUT
```

Мікросхема **74LVC1G04** виконує буферизацію та інвертування сигналу.

Резистор R2 використовується для послідовного узгодження виходу. Разом із власним вихідним опором логічного драйвера він формує вихід, придатний для підключення до лінії з хвильовим опором 50 Ом.

## Живлення

Плата живиться від напруги **3.3 В**.

Роз’єм живлення J2:

| Контакт | Сигнал |
|---|---|
| 1 | +3.3 V |
| 2 | GND |

Біля мікросхеми U1 встановлений розв’язувальний конденсатор **C1 100 нФ**.

## Роз’єми

### J1 — вхід 1PPS

Роз’єм Dupont 2.54 мм на 2 контакти.

| Контакт | Сигнал |
|---|---|
| 1 | 1PPS_IN |
| 2 | GND |

### J2 — вхід живлення

Роз’єм Dupont 2.54 мм на 2 контакти.

| Контакт | Сигнал |
|---|---|
| 1 | +3.3 V |
| 2 | GND |

### J4 — вихід 1PPS

BNC female PCB.

- центральний контакт — `1PPS_OUT`;
- екран — `GND`;
- номінальний імпеданс інтерфейсу — 50 Ом.

## Основні компоненти

| Позначення | Компонент | Номінал / тип |
|---|---|---|
| U1 | Логічний інвертор | 74LVC1G04 |
| R1 | Резистор | 100 Ом |
| R2 | Вихідний послідовний резистор | 33 Ом |
| C1 | Розв’язувальний конденсатор | 100 нФ |
| J1 | Вхід 1PPS | Dupont 2.54 мм, 2 контакти |
| J2 | Вхід живлення | Dupont 2.54 мм, 2 контакти |
| J4 | Вихід 1PPS | BNC female PCB, 50 Ом |

## Друкована плата

Плата розроблена у **KiCad**.

Поточна версія має **односторонню розводку**.

Сигнальні доріжки, доріжки живлення та полігон землі розміщені на одному мідному шарі.

Використані ширини доріжок:

- сигнал 1PPS — приблизно 0.30 мм;
- вихідний сигнал 1PPS — приблизно 0.30–0.40 мм;
- живлення 3.3 В — приблизно 0.50 мм;
- GND — полігон землі.

Доріжки між **U1, R2 та BNC-роз’ємом** виконані максимально короткими для зменшення спотворень сигналу.

Конденсатор C1 розташований максимально близько до U1.

На платі також передбачені монтажні отвори під **гвинти M2**.

## Відтворення проєкту

### 1. Встановлення KiCad

Необхідно встановити сумісну версію KiCad.

### 2. Завантаження репозиторію

Репозиторій можна клонувати командою:

```bash
git clone <посилання-на-репозиторій>
```

Або завантажити архів ZIP безпосередньо з GitHub.

### 3. Відкриття проєкту

Необхідно відкрити файл:

```text
*.kicad_pro
```

у папці `KiCad`.

Проєкт містить:

- принципову схему;
- розводку друкованої плати;
- посадочні місця компонентів;
- електричні з’єднання;
- контур плати.

### 4. Перевірка принципової схеми

У Schematic Editor необхідно перевірити сигнальний тракт:

```text
1PPS_IN -> R1 -> U1 -> R2 -> 1PPS_OUT
```

Живлення:

```text
3.3 V -> U1
      -> C1
```

Перед переходом до PCB необхідно запустити **Electrical Rules Checker (ERC)**.

### 5. Перевірка друкованої плати

У PCB Editor необхідно перевірити:

- розташування компонентів;
- трасування доріжок;
- полігон GND;
- розташування BNC-роз’єму;
- монтажні отвори M2;
- підписи на шовкографії.

Перед виготовленням необхідно запустити **Design Rules Checker (DRC)**.

## Підготовка файлів для виробництва

Gerber-файли формуються у KiCad через:

```text
File -> Plot
```

Файли свердління формуються через:

```text
Generate Drill Files
```

Отримані виробничі файли необхідно зберегти у папці:

```text
Gerber/
```

## Перевірка готової плати

Після монтажу компонентів:

1. Подати живлення 3.3 В на J2.
2. Підключити вихід 1PPS GPS-приймача u-blox M8N до J1.
3. Підключити осцилограф до BNC-виходу J4.
4. Перевірити наявність одного імпульсу за секунду.
5. Порівняти сигнал на вході та виході плати.
6. Переконатися, що вихідний сигнал інвертований.
7. Перевірити фронт і спад вихідного імпульсу.
8. Переконатися у відсутності значних спотворень сигналу.

## Призначення проєкту

Метою проєкту є розробка компактної друкованої плати, яка приймає сигнал синхронізації **1PPS від GPS-приймача**, буферизує та інвертує його і формує зручний BNC-вихід для підключення зовнішнього вимірювального або синхронізуючого обладнання.

Проєкт містить усі основні файли, необхідні для відкриття, перевірки, редагування та повторного виготовлення плати.
